# 💚 Lantern Corps — DC Emotional Spectrum

Um site inspirado no universo das **Lanternas da DC Comics**, desenvolvido com **HTML, CSS e JavaScript**.

O projeto transforma o conceito do **Espectro Emocional** em uma interface futurista, utilizando cores neon, efeitos de energia, animações e elementos geométricos criados com CSS.

---

## 🟢 Sobre o projeto

O **Lantern Corps** apresenta as principais Tropas do Espectro Emocional da DC, mostrando suas respectivas cores, emoções e características.

A proposta foi criar uma experiência visual inspirada em interfaces futuristas e no universo das Lanternas, **sem utilizar fotografias**. Os efeitos visuais são construídos utilizando HTML e CSS.

## ✨ Funcionalidades

* 🌌 Interface inspirada em ficção científica
* 💡 Efeitos de brilho neon
* 💍 Representação visual dos anéis
* 🎨 Cores diferentes para cada Tropa
* 🖱️ Cards interativos
* 📖 Informações sobre cada Tropa
* 🎲 Sistema de escolha aleatória de uma Tropa
* 📱 Design responsivo
* 📱 Menu para dispositivos móveis
* ✨ Animações em CSS
* 🚫 Sem utilização de imagens ou fotografias

---

## 🛠️ Tecnologias utilizadas

### HTML5

Utilizado para criar a estrutura das páginas e seus elementos.

### CSS3

Responsável pelo design, responsividade, animações, efeitos neon e identidade visual.

### JavaScript

Utilizado para adicionar interatividade ao site, incluindo os cards, modais, escolha aleatória de Tropa e menu mobile.

## 🚀 Como executar

Não é necessário instalar nenhuma dependência.

### 1. Clone o repositório

```bash
git clone https://github.com/TordYamagata/Tulen.git
```

### 2. Entre na pasta

```bash
cd Tulen
```

### 3. Abra o projeto

Abra o arquivo:

```text
index.html
```

Você também pode utilizar a extensão **Live Server** no Visual Studio Code para visualizar o projeto em tempo real.

## 💍 Sistema de escolha da Tropa

O projeto possui uma funcionalidade que permite ao usuário descobrir aleatoriamente qual Tropa poderia escolhê-lo.

Ao clicar em:

```text
DISCOVER YOUR CORPS
```

o JavaScript seleciona aleatoriamente uma das Tropas disponíveis e apresenta suas informações.

O site foi desenvolvido para funcionar em diferentes tamanhos de tela:
